# CarsonOS Website

The official website for the CarsonOS Linux distribution family and related operating system projects.

## Website

This repository is designed for GitHub Pages. The site is a standalone `index.html` file built with HTML, CSS, and JavaScript. It does not require a framework, build step, or external dependencies.

## Publish with GitHub Pages

1. Open the repository **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/(root)` folder.
5. Save your settings.

Once GitHub Pages finishes deploying, the site will be available at:

https://carjam120443-netizen.github.io/CarsonOS-Website/
